# Velvet Scroll

A free ebook library and auto-scrolling reader that runs in your browser. It opens DRM-free EPUB, MOBI, AZW3 and PDF files, scrolls them at a steady pace under a reading guide, and keeps your place.

Books and reading positions are stored only in each reader's own browser. Nothing is uploaded to this site.
